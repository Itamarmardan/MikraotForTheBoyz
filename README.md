# מקראות ישראל – בנק שאלות

אתר תרגול בחירה-מרובה. נפתח בדפדפן דרך `index.html` (גם בלחיצה כפולה על הקובץ).

## מבנה
- `index.html` – הדף
- `css/style.css` – עיצוב
- `js/app.js` – לוגיקת המבחן
- `js/topics.js` – שמות הנושאים
- `js/questions.js` – **בנק השאלות** (כאן מוסיפים)

## הוספת שאלה
פותחים את `js/questions.js` ומוסיפים שורה תחת הנושא המתאים:

```js
{c:'mk1',q:'השאלה?',o:['תשובה א','תשובה ב','תשובה ג','תשובה ד'],a:1,e:'הסבר (לא חובה)'},
```

- `a` – מספר התשובה הנכונה: 0=א, 1=ב, 2=ג, 3=ד. שתי תשובות נכונות: `a:[0,2]`
- נושא חדש: מוסיפים שורה ב-`js/topics.js` וכפתור ב-`index.html` (`data-chapter`).
- שאלה פגומה מופיעה באזהרה בקונסול (F12).

## פרסום
GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
